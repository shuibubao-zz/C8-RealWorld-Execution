## 4. 切换到真实数据源（需授权后再做）

1. 获得群数据所有者授权，明确可采集范围与脱敏要求；
2. 安装并启动 `chatlog`（或导出 wechat-cli JSONL），确认服务在 `127.0.0.1:5030`；
3. 用显式数据源跑桥接，**检查元数据里的 `synthetic` 必须为 `false`**：

```bash
python demo/wechat_bridge.py --source chatlog --chatlog-url http://127.0.0.1:5030 \
       --group <群ID或备注名> --days 7 --output evidence/sample_output.jsonl
cat evidence/sample_output.meta.json     # 确认 source / synthetic 字段
```

4. 重跑 `run_pipeline.py`（注意：pipeline 默认仍用合成源，接真实源需把对应步骤的 `--source` 参数改为 `chatlog`，或先用 `--source jsonl --input <导出文件>` 生成 `sample_output.jsonl` 后跳过桥接步骤）；
5. 重新人工标注一份**独立**测试集，更新 `classifier_metrics.json` 的准确率口径；
6. 重新生成 `sha256_清单.txt`，并在验收矩阵里把 L1-5 / L4-6 从 `not_met` 改为实测值。

> ⚠️ 不要把合成样本的准确率数字沿用到真实数据上；两者不可比。
